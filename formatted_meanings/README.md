# Formatted Meanings

Plain-language explanations, thematic summaries, and interpretive notes derived from the source editions in this repository.

## Purpose

Explain what paragraphs, chapters, passages, symbols, arguments, and themes mean without turning the explanation into a fictional narrative.

## Editorial rules

- Identify the exact source book, edition, chapter/section, and page or paragraph range.
- Separate direct textual evidence from explanation and interpretation.
- Explain difficult language, references, symbolism, historical context, and argument structure where supported.
- Label disputed interpretations and offer alternatives when the evidence permits more than one reading.
- Do not state speculation as fact or attribute later traditions to the source without evidence.
- Preserve important qualifications and note textual uncertainty.
- Cross-reference related passages when useful.

## Suggested organization

Create one subdirectory per book or source work, then organize files by chapter, section, or theme. Use Markdown (`.md`) for notes and finished explanations.

Suggested file naming:
`<book-slug>-chapter-<number>-meaning.md`

## Suggested meaning document structure

1. Title
2. Source and passage covered
3. Short summary
4. Explanation by paragraph or topic
5. Key themes and concepts
6. Interpretive questions or uncertainties
7. Related passages and references

## Production workflow

Follow [`docs/formatted-content-pipeline.md`](../docs/formatted-content-pipeline.md) from the repository root. Start new documents from [`_templates/meaning-template.md`](_templates/meaning-template.md). Explanations must distinguish explicit textual evidence from interpretation and remain grounded in the identified source passage.
