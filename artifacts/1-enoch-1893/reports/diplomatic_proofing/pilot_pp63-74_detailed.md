## Pilot Conclusions (pp.63–74)

1. **Lower match rate** — 7/105 segments (7%) vs 17% for pp.75–84. Causes:
   - Heavy Greek column on pp.65–68 (right column = Greek text, OCR noise)
   - Interpolation brackets not detected by OCR
   - Line-break hyphenation fragments verses across OCR segments

2. **Greek column problem** — pp.65, 66, 68 have substantial Greek parallel text. OCR on `eng+grc` produces garbled mix. Need column-aware OCR or Greek-only pass.

3. **Interpolation detection** — Charles marks VI.3–8, VIII.1–3, IX.7, X.1–3 with brackets. Repo has them bracketed. OCR doesn't see brackets. Must verify bracket positions from page images.

4. **High similarity where matched** — 96–97% for clean narrative verses (IX.1, X.7). Confirms repo body text is very close to Charles 1893.

5. **Name variants** — "Rafael" (Charles) vs "Raphael" (repo) — repo uses modernized spelling.
