# Source Notes — Vitruvius, The Ten Books on Architecture

## Edition
Vitruvius, *The Ten Books on Architecture*, translated by Morris Hicky Morgan. Cambridge: Harvard University Press, 1914.

## Translator/editor history
The 1914 preface says Morgan completed the translation except for the final four chapters of Book X. Herbert Langford Warren completed the translation from Book X, Chapter XIII onward and assumed responsibility for that section. Warren also identifies editorial changes to earlier portions.

## Repository source

The repository file is a scan-derived OCR transcription. It contains OCR noise, including misread words, Roman numerals, Greek terms, punctuation, and line breaks.

## Scope and partition
This edition contains the complete source file divided into front matter, Books I–X, and index/end matter. The extracted text ranges are contiguous and reconstruct the original source file exactly. No source wording was changed in the partitioning pass.

## Verification limits
The exact range reconstruction proves that no characters were lost or duplicated during file splitting. It does not prove the OCR is accurate or that the source transcription matches every printed page. Facsimile collation remains necessary.
