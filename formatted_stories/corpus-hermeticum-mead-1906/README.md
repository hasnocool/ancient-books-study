# Corpus Hermeticum — Formatted Stories

Narrative summaries derived from G. R. S. Mead's 1906 English translation in *Thrice-Greatest Hermes*, Volume II.

## Editorial rules

- Stories summarize the translated tractates; they are not new translations or reconstructions.
- Preserve each tractate's sequence, claims, and qualifications.
- Do not invent scenes, dialogue, motives, or historical events.
- Keep the translator's terminology visible where it matters.
- Identify the source file and retain provisional status until the formatted text is collated against the 1906 facsimile.
- Keep summaries distinct from explanations and speculative modern interpretations.
