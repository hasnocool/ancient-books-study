## Editorial notes

Chapter 1 retains the transcription's unusual names and descriptive details. The bracketed presentation of “and Gaidal” has not been normalized. Chapters 3–5 describe the first heaven using the source's cosmological vocabulary; the adaptations do not translate that vocabulary into modern scientific mechanisms.

This pilot covers chapters 1–5 only. It does not complete the 68-chapter work or assess the separate five-section Melchizedekian appendix.
